# agent-skills
Skills for coding agents

## Installation

Install the skills as a Claude Code plugin:

    /plugin install splitbrain --marketplace splitbrain/agent-skills

This also installs the [plain-writing skill](https://github.com/docwriter-org/plain-writing-skill) as a
dependency. The `writing-rules` skill uses it.

## Updates

Auto-update is off by default for third-party marketplaces. To enable it, run `/plugin`, open the
**Marketplaces** tab, select `splitbrain` and choose **Enable auto-update**.

To update manually, run `/plugin marketplace update splitbrain`.
